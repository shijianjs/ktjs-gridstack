<ktjs-features section-title="Why write animations in Kotlin" tinted>

<ktjs-feature icon="lucide:layout-dashboard" title="The whole layout API">Add, move, resize, compact, change the column count, save and reload a layout — all typed.</ktjs-feature>

<ktjs-feature icon="lucide:list-checks" title="Typed options">`gridStackOptions { … }` covers the ~40 upstream options, so a misspelled one is a compile error.</ktjs-feature>

<ktjs-feature icon="lucide:move" title="Elements and selectors">Every method that accepts a selector upstream has a `…BySelector` twin, so both styles type-check.</ktjs-feature>

<ktjs-feature icon="lucide:flask-conical" title="Tested in Chromium">The module's tests build real grids and assert positions; the demo's Playwright suite clicks the dashboard buttons.</ktjs-feature>

<ktjs-feature icon="lucide:book-open" title="Docs in two languages">Every page exists in English and Simplified Chinese, with the same structure, and links out to the demo and the Dokka reference.</ktjs-feature>

</ktjs-features>
